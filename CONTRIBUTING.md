# Contributing

Shocked is proprietary software. This repository is primarily the public distribution, documentation, support, and release channel for compiled Shocked packages.

## Issues and feature requests

Bug reports, compatibility reports, documentation corrections, and feature requests are welcome through the GitHub issue forms once the repository is public.

Before posting, review logs and diagnostics for credentials or unrelated personal information.

## Source contributions

Publication of this repository does not grant access to Shocked's proprietary source code or permission to create derivative works. Do not submit reconstructed, decompiled, or reverse-engineered source as a contribution.

If source contributions are opened in the future, their terms and workflow will be documented separately.

## Security reports

Do not open a public issue for a vulnerability that would expose exploit details or private information. Follow [SECURITY.md](SECURITY.md).

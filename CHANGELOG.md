# Changelog

## 30.0.0-8 — Current public release

- Reworked Limit Break into rolling, non-consecutive charging.
- Retuned Limit Break workload detection for high-core-count systems.
- Removed the near-maximum-frequency entrance requirement for Limit Break.
- Added the Console setting that enables or disables forced AC brightness authority.
- Restored the global systemd user-session tray autostart link in the Debian package.
- Preserved unrelated daemon, CLI, tray, Console, CPU, GPU, thermal, battery, IPC, and service functionality.
- Completed the Rust verification suite with 95 tests passing and no failures.
